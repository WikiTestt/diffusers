## Подробные руководства

Здесь собраны детальные инструкции по работе с системой.

### Работа с содержимым

#### Форматирование текста

Используйте стандартный Markdown для форматирования:

- **Жирный текст** - `**текст**`
- *Курсив* - `*текст*`
- `Код` - `` `код` ``

#### Списки и структура

Создавайте упорядоченные и неупорядоченные списки:

1. Первый элемент
2. Второй элемент
   - Подпункт
   - Еще подпункт

#### Ссылки

Добавляйте ссылки между страницами:
```markdown
[текст ссылки](url-страницы)
```
