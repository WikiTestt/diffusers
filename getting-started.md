## Добро пожаловать!

Это руководство поможет вам начать работу с нашей системой.

### Шаг 1: Знакомство

Ознакомьтесь с основными разделами документации:
- Изучите [руководства](guides) для детальных инструкций
- Проверьте [FAQ](faq) для быстрых ответов

### Шаг 2: Основные концепции

**Структура проекта**
- Все страницы написаны в формате Markdown
- Навигация настраивается в `_config.yml`
- Стили находятся в папке `assets/css/`

**Создание новых страниц**
1. Создайте файл `.md` в корне проекта
2. Добавьте YAML Front Matter с layout и title
3. Напишите контент в Markdown

### Шаг 3: Что дальше?

Теперь вы готовы к работе! Переходите к конкретным [руководствам](guides) для углубленного изучения.
