# Wan 2

**Wan 2** — серия открытых моделей для генерации видео, разработанная командой Wan-AI.

## Основные модели

| Модель | Тип | Разрешения | Ссылка |
|--------|-----|------------|---------|
| **Wan2.2-T2V-A14B** | Text-to-Video | 480P, 720P | [Hugging Face](https://huggingface.co/Wan-AI/Wan2.2-T2V-A14B) |
| **Wan2.2-I2V-A14B** | Image-to-Video | 480P, 720P | [Hugging Face](https://huggingface.co/Wan-AI/Wan2.2-I2V-A14B) |
| **Wan2.2-S2V-14B** | Speech-to-Video | 480P, 720P | [Hugging Face](https://huggingface.co/Wan-AI/Wan2.2-S2V-14B) |
| **TI2V-5B** | Компактная модель | 720P | Эффективная версия для потребительских GPU |

## Ключевые особенности

### 1. MoE архитектура с двухэтапным процессом
Wan2.2 использует инновационную архитектуру Mixture-of-Experts с разделением на два отдельных диффузера:

#### High Noise Model + Low Noise Model
- **High Noise модель** — обрабатывает высокий уровень шума (ранние стадии денойзинга)
- **Low Noise модель** — рафинирует результат на низком уровне шума (финальные стадии)
- **Двухэтапный процесс** — аналогично рефайнеру в SDXL, сначала генерация, затем улучшение
- **Увеличенная емкость** при сохранении вычислительных затрат

#### Файлы моделей
Для работы Wan2.2-I2V-A14B требуется скачать две отдельные модели:
- `high_noise_model.safetensors` — для начальных стадий денойзинга
- `low_noise_model.safetensors` — для финального рафинирования

### 2. Кинематографическая эстетика
- Тщательно подобранные эстетические данные
- Детальная разметка освещения, композиции, контраста, цветовой гаммы
- Возможность создания видео с настраиваемыми эстетическими предпочтениями

### 3. Сложные движения
По сравнению с Wan2.1:
- **+65.6%** больше изображений в обучающих данных
- **+83.2%** больше видео в обучающих данных
- Улучшенная генерация сложных сцен и движений

### 4. Точное соответствие семантике
- Сложное понимание сцен
- Генерация множественных объектов
- Лучшее восстановление творческих намерений

## Технические характеристики

### Производительность
- **Wan2.2 MoE** демонстрирует наименьшую валидационную потерю
- Генерированное видео максимально близко к ground-truth
- Превосходная сходимость модели

### Поддерживаемые форматы
- **Разрешения**: 480P (480x832), 720P
- **Частота кадров**: 16fps (по умолчанию), 24fps (5B модель)
- **Длительность**: до 5-8 секунд стабильной генерации

### Варианты моделей
- **5B модель**: более быстрая, поддерживает 24fps
- **14B модель**: улучшенное качество, стандартный выбор
- **27B модель**: экспериментальная версия с максимальным качеством

### Компрессия
Wan2.2-VAE обеспечивает:
- **Базовая компрессия**: 4×16×16
- **Общая компрессия**: до 64x с сохранением качества
- **С patchification**: до 4×32×32

## Системные требования

### Эффективная модель (TI2V-5B)
- **GPU**: Одна потребительская видеокарта
- **Время генерации**: менее 9 минут для 5-секундного 720P видео
- **Статус**: Один из самых быстрых генераторов 720P@24fps видео

### Высокопроизводительные модели
- Требуют более мощное оборудование
- Поддерживают различные оптимизации для разных конфигураций

### Рекомендации сообщества
Согласно опыту пользователей из русскоязычного сообщества:

#### Минимальные требования
- **GPU**: RTX 3070 (8GB VRAM)
- **RAM**: 12-24GB системной памяти
- **Время генерации**: RTX 3060 — около 5-6 минут

#### Оптимальная конфигурация
- **GPU**: RTX 4070 Ti или лучше
- **Время генерации**: RTX 4070 Ti — 32-34 секунды
- **RAM**: 48-96GB для максимального комфорта

#### Высокопроизводительная конфигурация
- **GPU**: RTX 4090 / RTX 5090
- **Результат**: Значительно быстрее генерация
- **Подходит для**: Профессиональной работы и экспериментов

## Lightning LoRA

**Wan2.2-Lightning** — ускоренная версия модели через дистилляцию, обеспечивающая **20x ускорение** при сохранении качества.

### Основные преимущества
- **Скорость**: Генерация видео всего за 4 шага без CFG
- **Качество**: Визуальные результаты на уровне базовой модели, иногда даже лучше
- **Сложные движения**: Сохраняет отличную динамику движений несмотря на сокращение до 4 шагов

### Доступные Lightning модели
| Модель | Тип | Особенности |
|--------|-----|-------------|
| **Wan2.2-T2V-A14B-NFE4** | Text-to-Video Lightning | 480P/720P, портрет/пейзаж |
| **Wan2.2-I2V-A14B-4steps** | Image-to-Video Lightning | 480P/720P, rank64 LoRA |

**Рекомендуемая LoRA для ускорения:**
- [Wan2.2-I2V-A14B-4steps-lora-rank64-Seko-V1](https://huggingface.co/lightx2v/Wan2.2-Lightning/tree/main/Wan2.2-I2V-A14B-4steps-lora-rank64-Seko-V1)
- Работает отдельно для high_noise и low_noise моделей

### Ссылки Lightning

## Практические советы

### Оптимизация для слабых GPU
- Использовать квантизированные/масштабированные версии моделей
- Рассмотреть TI2V-5B как более эффективную альтернативу
- Настроить параметры CFG и количество шагов для баланса качества/скорости

### Настройка workflow
- ComfyUI рекомендуется для упрощения настройки
- Экспериментировать с различными LoRA для улучшения результатов
- Подбирать оптимальные параметры steps и CFG индивидуально

### Распространенные проблемы
- **Высокие требования к VRAM**: рассмотреть использование offload опций
- **Вариации качества**: между версиями моделей могут быть заметные различия
- **Сложность настройки**: требует времени на изучение оптимальных параметров
- **Ограничения длительности**: стабильная генерация до 5-8 секунд, после 9 секунд движения становятся нестабильными
- **Согласованность деталей**: сложности с сохранением лиц и мелких деталей на протяжении видео

### Техники оптимизации из сообщества

#### Ускорение генерации
- **lightx2v LoRA**: может сократить время генерации с 10 минут до 1 минуты
- **Sage Attention + Triton**: дополнительное ускорение генерации
- **4-5 sampling steps**: оптимальное количество для баланса скорости/качества
- **Rank 32-64 LoRA**: рекомендуемые значения для лучших результатов

#### Улучшение качества
- **Multi-prompt техника**: для более детального контроля результата
- **Context nodes**: для генерации более длинных видео через сцепление
- **Легкие LoRA с весом 0.5-1**: для тонкой настройки без потери качества
- **Двухмодельный подход**: использование отдельных моделей для high/low noise

#### Работа с ограниченной VRAM
- **Квантизированные GGUF модели**: для GPU с меньшим объемом памяти
- **Различные конфигурации noise steps**: эксперименты с распределением шагов между моделями

### Сценарии использования Image-to-Video
Wan2.2 поддерживает два основных подхода для img2vid генерации:

#### 1. Одиночный кадр
- **Первый кадр**: подача начального изображения, модель генерирует последующие кадры
- **Последний кадр**: подача финального изображения, модель генерирует предшествующие кадры

#### 2. Парные кадры
- **Переход между кадрами**: подача двух изображений (начальное + конечное)
- **Интерполяция**: модель автоматически анимирует переход между заданными состояниями
- **Более контролируемый результат**: четкое определение начальной и конечной точек анимации

### NSFW контент
Как отмечено в сообществе:
- **Без LoRA:** WAN не может генерировать NSFW контент в базовой конфигурации
- **С LoRA:** поддержка NSFW генерации в режиме img2vid
- **Ограничения LoRA:** большинство доступных LoRA "деревянные" и натренированы на реализм
- **Аниме-контент:** простая анимация персонажей (например, лисы) работает без LoRA, проблемы возникают с взаимодействиями
- **Источники LoRA:** множество моделей доступно на Civitai
