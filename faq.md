## Часто задаваемые вопросы

### Общие вопросы

**Что такое Jekyll?**

Jekyll - это генератор статических сайтов. Он преобразует текстовые файлы в готовый веб-сайт.

**Как добавить новую страницу?**

1. Создайте файл `.md` в корневой папке
2. Добавьте заголовок с параметрами:
   ```yaml
   ---
   layout: default
   title: Название страницы
   ---
   ```
3. Напишите содержимое в Markdown

**Как обновить навигацию?**

Отредактируйте секцию `navigation` в файле `_config.yml`:

```yaml
navigation:
  - title: Название
    url: /url-страницы
```

### Технические вопросы

**Где находятся стили?**

Все CSS-стили находятся в файле `assets/css/style.css`.

**Можно ли использовать HTML?**

Да, в Markdown-файлах можно использовать HTML-теги при необходимости.

**Как собрать сайт локально?**

```bash
jekyll serve
```

Сайт будет доступен по адресу `http://localhost:4000`
